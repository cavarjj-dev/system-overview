# Operator system

Public map of one practice operator system. A template for a bespoke build. Not a client portal.

The page is a snapshot. It is refreshed from the operator machine and published on purpose. A timer does not publish it.

Not in this repository, ever:

- Keys, tokens, or account files
- Client names, session content, or client files
- Other people's names, conversations, phone numbers, or files
- The private cockpit

Viewer: `index.html`. Record: `overview.json`.
